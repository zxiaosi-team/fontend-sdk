## 安装依赖

```sh
# 一定要用 pnpm
pnpm install
```

## 项目启动

```sh
# sdk 打包
npm run build:sdk

# 启动主应用
npm run dev:main
# 启动子应用
npm run dev:subapp1
npm run dev:subapp2
```
